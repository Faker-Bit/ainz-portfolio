# 🛸 anzar.dev (`ainz-portfolio`)

Interactive developer portfolio for **Anzar (`Faker-Bit`)** featuring an **Alien Bioluminescent Theme**, an interactive **Code-Wall Intro (`/`)**, a **Neovim Portfolio IDE (`/site/`)**, and a **Real-Time 20 FPS Cristiano Ronaldo CR7 `SIUUUUU!` Braille ASCII Hologram Engine**.

---

## ✨ Features

1. **Interactive Code-Wall Intro (`/`)** — [`index.html`](./index.html), [`glimpse.js`](./glimpse.js), [`glimpse.css`](./glimpse.css)
   - Syntax-highlighted code wall (`wall.json`) with ghost editor cursor, live ASCII/glyph eye & face matrix (`face.webm` / `face-track.json`), interactive keyboard glass overlay, floating terminal widgets, and `:theme` color-scheme switcher across 29 themes (defaulting to the custom `alien` bioluminescent theme).
   - Press **`Enter`** anywhere to dive straight into the Neovim projects buffer.
2. **Real-Time Animated CR7 `SIUUUUU!` Braille ASCII Stage (`[S]` / `:suii`)** — [`intros/shared/alien-suii.js`](./intros/shared/alien-suii.js), [`intros/shared/alien-suii.css`](./intros/shared/alien-suii.css)
   - Press **`S`** anywhere (or click **`⚽ CR7 SIUUUUU! ASCII [S]`**) to launch the multi-stage jump-spin-landing celebration with WebAudio stadium synth & sub-bass impact.
   - Features **5 live-animated `emojicombos.com` Braille ASCII masterpieces** (`[1]`–`[5]`) with 20 FPS rising plasma sparks, golden `#7` jersey shimmer waves, mid-air levitation wind streaks, and sonic boom roar ripples.
3. **Neovim Portfolio IDE (`/site/`)** — [`site/index.html`](./site/index.html), [`site/editor.js`](./site/editor.js), [`site/editor.css`](./site/editor.css)
   - Full Neovim-style portfolio buffer (`~/Projects`) showcasing [`Faker-Bit`](https://github.com/Faker-Bit) repositories (`ai-agent-learning`, `CR7-SIUUU-ASCII`, `ZEXR`, `nexus-ai`, `nexus`) with an interactive 3D/wheel file tree, animated SVG preview cards, `WORM` / `EYE` / `GHOST` status bar, `VISITORS` sparkline, blueprint hero (`whoami`), and git contribution calendar.

---

## 🚀 Quick Start

```bash
npm start
```

Then open:
- **Intro (Code Wall + CR7 `SIUUUUU!` Stage):** `http://localhost:3000/`
- **Neovim Portfolio IDE (`~/Projects`):** `http://localhost:3000/site/`
- **GitHub Profile & Customizer:** `http://localhost:3000/github/`
